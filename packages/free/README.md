# Motion Pricing Free

Accessible React pricing cards with typed props, monthly/yearly billing, light/dark themes, and no third-party runtime dependencies beyond React.

[![npm version](https://img.shields.io/npm/v/%40motion-pricing%2Ffree?logo=npm&label=version)](https://www.npmjs.com/package/@motion-pricing/free)
[![npm downloads](https://img.shields.io/npm/dm/%40motion-pricing%2Ffree?logo=npm&label=downloads)](https://www.npmjs.com/package/@motion-pricing/free)

```sh
npm install @motion-pricing/free
```

```tsx
import { PricingTable, defaultPlans } from '@motion-pricing/free';
import '@motion-pricing/free/styles.css';

<PricingTable plans={defaultPlans} billingCycle="monthly" />
```

See the repository documentation for the complete API and customization guide.
