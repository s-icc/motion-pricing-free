# Customization

Start by changing plan data rather than CSS. Free styles are scoped under `.mp-pricing`; override variables on a wrapper or via `style`:

```css
.brand-pricing {
  --mp-accent: #1769ff;
  --mp-bg: #f4f7ff;
  --mp-surface: #fff;
  --mp-text: #101529;
}
```

Keep text contrast at WCAG AA levels and preserve the built-in focus indicators.
